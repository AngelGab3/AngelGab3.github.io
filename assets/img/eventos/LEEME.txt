===================================================================
 GUÍA PARA AGREGAR FOTOS DE TUS EVENTOS (ÁNGEL MUNGUÍA)
===================================================================

¡El sistema de galería y optimización es 100% automático!

1. ¿CÓMO AGREGAR FOTOS A UN EVENTO EXISTENTE?
----------------------------------------------
Solo copia tus fotos (formatos soportados: .jpg, .jpeg, .png, .webp, .heic)
dentro de la carpeta correspondiente (en carpetas vacías no se muestra nada):

- assets/img/eventos/2026-05-planetario-puebla/       -> Fotos del Planetario
- assets/img/eventos/2026-03-infomatrix-san-luis/      -> Fotos de Infomatrix (Oro)
- assets/img/eventos/2025-2026-talleres-stem-udlap/    -> Taller Cuántica y STEM UDLAP
- assets/img/eventos/2025-10-nasa-space-apps/          -> NASA Space Apps
- assets/img/eventos/2025-05-ios-development-lab/      -> Hackathon Apple / iOS Lab
- assets/img/eventos/2025-voluntariado-imav-mexcir/    -> Voluntariado IMAV y MEXCIR
- assets/img/eventos/2025-smgs-astrofisica/            -> Gráficos / fotos SMGs
- assets/img/eventos/2024-10-congreso-smf-chihuahua/   -> Congreso SMF (Efecto Faraday)
- assets/img/eventos/2023-2025-noche-de-las-estrellas/ -> Noche de las Estrellas

2. OPTIMIZACIÓN, CONVERSIÓN HEIC Y PRIVACIDAD AUTOMÁTICAS
---------------------------------------------------------
Antes de construir el sitio, scripts/process_event_photos.py:
- Convierte automáticamente fotos .heic (iPhone) a .jpg.
- Corrige la rotación EXIF y ELIMINA metadatos EXIF/GPS (privacidad).
- Comprime cualquier foto a < 300 KB y genera versiones WebP cacheadas (400w, 800w, 1600w).

3. ¿EN QUÉ ORDEN SE MUESTRAN Y CÓMO PERSONALIZAR?
-------------------------------------------------
Orden automático de las fotos:
  1) Prefijo numérico en el nombre (01_domo.jpg, 02_premio.jpg, ...)
  2) Fecha de captura EXIF (leída antes de limpiar metadatos)
  3) Nombre alfabético

Cada carpeta puede tener un archivo opcional evento.yml con:
  titulo_es, titulo_en, fecha (YYYY-MM-DD), lugar,
  descripcion_es, descripcion_en, portada: archivo.jpg, pie_de_foto.

4. ¿CÓMO CREAR UN NUEVO EVENTO EN EL FUTURO?
--------------------------------------------
Paso A: Crea una nueva carpeta en assets/img/eventos/, por ejemplo:
        assets/img/eventos/2027-04-mi-nuevo-evento/
Paso B: Agrega tus fotos adentro (y opcionalmente un archivo evento.yml).
        ¡No necesitas editar ningún archivo .md! Aparecerá automáticamente en /galeria/.
Paso C (opcional): Si también quieres incrustar esa galería en una página o proyecto,
        añade:
        {% include event_gallery.liquid folder="2027-04-mi-nuevo-evento" title="Mi Nuevo Evento" %}

Haz git add, git commit y git push para publicar los cambios.
